# Skill Nexis - Week 1 Assignment

## Project: Python Programming Practice & Simple ATM Simulator

This repository contains the Week 1 assignments provided by Skill Nexis.

### Assignments Covered
1. **Temperature Converter** - Celsius ↔ Fahrenheit using functions.
2. **Student Grade Calculator** - accepts marks, calculates average and assigns a grade.
3. **Even/Odd & Prime Number Checker** - checks number type and prime status.
4. **Mini Project: Simple ATM Simulator** - PIN login, balance checking, deposit and withdrawal.

### Skills Gained
- Functions
- Loops
- Conditional statements
- Modular programming
- User input and validation

### Files
- `index.html` - main project interface
- `style.css` - styling and responsive design
- `script.js` - assignment logic and ATM functions

### How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Use each assignment section and test the inputs.
